manjaro gnome 42.3 bluetooth is not working

2022-07-13

我的蓝牙是 interl a200, 在某一次的滚动更新后, 我发现了两件事:

  1. 每次重启后发现, 蓝牙是默认关闭的
  2. gnome 的蓝牙面板, 无法打开蓝牙了

第一个问题对我的影响不大, 所以, 我没有打算处理第一个问题. 现在主要来讨论第二个问题. 先说解决方案

sudo modprobe -r btusb
sudo modprobe btusb

参考的资料有:

  1. https://forum.manjaro.org/t/intel-bluetooth-not-working/104849
  2. https://wiki.archlinux.org/title/Bluetooth#bluetoothctl:_No_default_controller_available

简单来说, 就是我执行 sudo bluetoothctl devices 的时候, 发现没有输入, 然后在 archlinux 的那篇文档也提到了相关的解决方案. 如果你发现你的电脑没有 bluetoothctl 命令的话, 可以通过安装 bluez-utils 来获取.

我顺便学到了一个 pacman 的命令, 就是 pacman -F xxx, 这个命令会告诉你, 如果你想使用 xxx 命令, 你可以安装哪些包来获取这个命令
