wsl2 移除 windows 环境变量

2023-05-08

不经意之间, 发现了这个问题, 其实通过 echo $PATH 也能观察到. 后面参考了这个地址, 把问题处理好了. 我大概列一下我用到的方案.

  1. 为了能在 wsl2 里面, 输入 code 能直接打开 vs code, 所以我在 .zshrc 文件里面添加了 vs code 的环境变量 export PATH="$PATH:/mnt/c/Users/<用户名>/AppData/Local/Programs/Microsoft VS Code/bin"
  2. 然后打开 /etc/wsl.conf, 添加 [interop] appendWindowsPath = false
