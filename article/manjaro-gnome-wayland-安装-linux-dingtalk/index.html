manjaro gnome wayland 安装 linux dingtalk

2022-01-29

记录一下配置的过程.

使用的是 yay 来安装的, 然后, 后续你有两个问题要解决:

  1. 缩放问题
  2. fcitx 输入法的问题

缩放问题

由于我使用的是 4k 分辨率的显示器, 所以我必须要调整缩放, 调整缩放的过程也很简单, 只需要在钉钉里面设置就行了, 如下图所示:

先点击左上角自己的头像, 然后就会弹出这个界面

fcitx 输入法的问题

执行 sudo vim /usr/bin/dingtalk 来打开这个文件, 把文件内容修改成下面这样就行了.

#!/bin/bash -e
cd /opt/dingtalk/release
QT_IM_MODULE=fcitx ./com.alibabainc.dingtalk
